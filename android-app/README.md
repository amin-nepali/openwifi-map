# OpenWifi by Amin for Android

This Android WebView app opens the public OpenWifi Map website and uses the shared logo asset for its launcher icon.

- App name: OpenWifi by Amin
- Version: 1.0 (version code 1)
- Minimum Android: 6.0 (API 23)
- APK output: `app/build/outputs/apk/debug/app-debug.apk`
- The debug APK is signed automatically by Gradle for installation and testing. Create and protect a separate release key before distributing through Google Play.

Build from this directory with `gradlew.bat assembleDebug`. The repository includes the Gradle wrapper; configure the Android SDK with `local.properties` or `ANDROID_HOME`.
